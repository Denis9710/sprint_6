Sprint_6 : Автотесты для Яндекс.Самокат
Проект автоматизации тестирования для учебного сервиса "Яндекс.Самокат" с использованием Selenium, Pytest и Allure Framework.

Описание
Данный проект содержит автоматизированные тесты для вэб-приложения "Яндекс.Самокат". Реализовано тесттирование ключевых функциональностей сервиса с использованием паттерна Page Object Model (POM).

Функциональности
Тестирование раздела FAQ - проверка выпадающих списков с вопросами Полный флоу заказа самоката - тестирование позитивных сценариев Проверка точек входа - верхняя и нижняя кнопки "Заказать" Тестирование навигации - логотипы Самоката и Яндекса Параметризованные тесты - multiple data sets

Технологический стек
Python 3.x - основной язык программирования Selenium 4.15.0 - автоматизация браузера Pytest 7.4.0 - фреймворк для тестирования Allure 2.13.0 - генерация отчетов Firefox - браузер для тестирования WebDriver Manager - автоматическое управление драйверами

Установка зависимостей
pip install -r requirements.txt

Запуск тестов
pytest tests/ -v

Запуск с генерацией Allure-отчета
pytest tests/ --alluredir=allure-results -v

Просмотр отчета
allure serve allure-results
